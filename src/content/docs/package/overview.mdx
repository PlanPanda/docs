## เปิดหน้าแพ็คเกจ

ไปที่ **ตั้งค่า → เลือก Package** — แพ็คเกจอยู่ในกลุ่มตั้งค่า ไม่ใช่เมนูหลัก

## การ์ดยอดคงเหลือ

ด้านบนของหน้า (และหน้าเติมเงิน / ประวัติพอยต์) จะแสดงสรุปให้เห็นชัด ๆ ว่าตอนนี้คุณใช้งานอยู่ในสถานะไหน

- **ยอดคงเหลือ** — จำนวนพอยต์ที่เหลืออยู่
- **แพ็คเกจปัจจุบัน** — ฟรี / เริ่มต้น / มืออาชีพ / ไม่จำกัด
- **ลูกค้า** — จำนวนที่ใช้อยู่เทียบขีดจำกัด เช่น "45 / 100 คน" (แถบจะเป็นสีแดงเมื่อใกล้เต็ม ตั้งแต่ 90% ขึ้นไป)

## เลือกแพ็คเกจ

	name="package/overview-cards"

/>

แต่ละแพ็คเกจแสดงราคาเป็น **X พอยต์/วัน** และจำนวนลูกค้าที่รองรับ:

| แพ็คเกจ   | ลักษณะ                            |
| --------- | --------------------------------- |
| **ฟรี**   | ใช้งานฟีเจอร์พื้นฐานฟรี            |
| **เริ่มต้น** | เหมาะสำหรับผู้เริ่มต้น             |
| **มืออาชีพ** | ฟีเจอร์ครบครันสำหรับมืออาชีพ      |
| **ไม่จำกัด** | ไม่จำกัดจำนวนลูกค้า               |

- แพ็คเกจที่ใช้อยู่จะมีป้าย **"กำลังใช้งาน"** (ปุ่มเปลี่ยนเป็น "แพ็คเกจปัจจุบัน")
- กด **"เลือกแพ็คเกจนี้"** → เปลี่ยนให้ทันที **ไม่ต้องชำระเงินเพิ่ม** ระบบจะเริ่มหักพอยต์ตามราคาแพ็คเกจใหม่เป็นรายวัน
- ถ้าจำนวนลูกค้าปัจจุบันเกินขีดจำกัดของแพ็คเกจที่เลือก ปุ่มจะขึ้น "เกินขีดจำกัด" ใช้ไม่ได้จนกว่าจะลดจำนวนลูกค้าให้พอดี

### เลือกแพ็คเกจอัตโนมัติ

ติ๊ก **"เลือกแพ็คเกจอัตโนมัติ"** — ระบบจะปรับเพิ่ม/ลดแพ็คเกจให้พอดีกับจำนวนลูกค้าที่มีอยู่จริงโดยอัตโนมัติ ลูกค้าเพิ่มก็ปรับขึ้น ลดลงก็ปรับลง ไม่ต้องมานั่งเลือกเอง

## ระบบหักพอยต์รายวัน

- ทุกวันระบบจะหักพอยต์ตามราคาแพ็คเกจที่ใช้ — ดูรายการ "ค่าบริการรายวัน" ได้ที่ [ประวัติพอยต์](/package/billing/)
- ถ้ายอดเงินต่ำกว่าราคาแพ็คเกจรายวัน ทั้งแอปจะเข้าสู่โหมดดูอย่างเดียว — ขึ้นแถบเตือน **"ยอดเงินไม่เพียงพอ — ไม่สามารถเพิ่มข้อมูลใหม่ได้"** พร้อมปุ่ม "เติมเงิน" บนทุกหน้าจนกว่าจะเติมเงิน

:::tip[เคล็ดลับ]
เปิด "เลือกแพ็คเกจอัตโนมัติ" ไว้จะสบายใจที่สุด — จ่ายเท่าที่ใช้จริง ลูกค้าลดลง ค่าใช้งานก็ถูกลงเอง 💡
:::
