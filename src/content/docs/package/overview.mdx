## เปิดหน้าแพ็คเกจ

ไปที่ **ตั้งค่า → เลือก Package** — แพ็คเกจอยู่ในกลุ่มตั้งค่า ไม่ใช่เมนูหลัก

## การ์ดยอดคงเหลือ

ด้านบนของหน้า (และหน้าเติมเงิน / ประวัติพอยต์) จะแสดงสรุปให้เห็นชัด ๆ ว่าตอนนี้คุณใช้งานอยู่ในสถานะไหน

- **ยอดคงเหลือ** — จำนวนพอยต์ที่เหลืออยู่
- **แพ็คเกจปัจจุบัน** — ฟรี / เริ่มต้น / มืออาชีพ / ไม่จำกัด
- **ลูกค้า** — จำนวนที่ใช้อยู่เทียบขีดจำกัด เช่น "45 / 100 คน" (แถบจะเป็นสีแดงเมื่อใกล้เต็ม ตั้งแต่ 90% ขึ้นไป)

## เลือกแพ็คเกจ

แต่ละแพ็คเกจแสดงราคาเป็น **X พอยต์/วัน** และจำนวนลูกค้าที่รองรับ:

| แพ็คเกจ      | ลักษณะ                       | ผู้ช่วย AI ระดับเริ่มต้น |
| ------------ | ---------------------------- | ------------------------ |
| **ฟรี**      | ใช้งานฟีเจอร์พื้นฐานฟรี       | ประหยัด                  |
| **เริ่มต้น**   | เหมาะสำหรับผู้เริ่มต้น        | มาตรฐาน                  |
| **มืออาชีพ** | ฟีเจอร์ครบครันสำหรับมืออาชีพ | มาตรฐาน                  |
| **ไม่จำกัด**  | ไม่จำกัดจำนวนลูกค้า          | ฉลาด                     |

"ผู้ช่วย AI ระดับเริ่มต้น" คือระดับที่ได้เมื่อเลือก **อัตโนมัติ** ในแชท — ไม่ได้จำกัดสิทธิ์ ทุกแพ็คเกจเลือกระดับอื่นเองได้ (ดู [เลือกระดับความฉลาด](/ai/assistant/#เลือกระดับความฉลาด)) ผู้ดูแลระบบอาจปรับการจับคู่นี้ได้

- แพ็คเกจที่ใช้อยู่จะมีป้าย **"กำลังใช้งาน"** (ปุ่มเปลี่ยนเป็น "แพ็คเกจปัจจุบัน")
- กด **"เลือกแพ็คเกจนี้"** → เปลี่ยนให้ทันที **ไม่ต้องชำระเงินเพิ่ม** ระบบจะเริ่มหักพอยต์ตามราคาแพ็คเกจใหม่เป็นรายวัน
- ถ้าจำนวนลูกค้าปัจจุบันเกินขีดจำกัดของแพ็คเกจที่เลือก ปุ่มจะขึ้น "เกินขีดจำกัด" ใช้ไม่ได้จนกว่าจะลดจำนวนลูกค้าให้พอดี

### เลือกแพ็คเกจอัตโนมัติ

ติ๊ก **"เลือกแพ็คเกจอัตโนมัติ"** (เปิดไว้เป็นค่าเริ่มต้น) — ระบบจะปรับเพิ่ม/ลดแพ็คเกจให้พอดีกับจำนวนลูกค้าที่มีอยู่จริงโดยอัตโนมัติ ลูกค้าเพิ่มก็ปรับขึ้น ลดลงก็ปรับลง ไม่ต้องมานั่งเลือกเอง

## ขีดจำกัดจำนวนลูกค้า

จำนวนลูกค้าที่เพิ่มได้ขึ้นกับแพ็คเกจ (นับรวมทั้งผู้มุ่งหวังและลูกค้า):

- **เปิดเลือกแพ็คเกจอัตโนมัติ** — เพิ่มลูกค้าได้ถึงขีดจำกัดของแพ็คเกจใหญ่สุด เพราะระบบจะปรับแพ็คเกจขึ้นให้เองเมื่อลูกค้าเพิ่ม
- **ปิดเลือกแพ็คเกจอัตโนมัติ** — เพิ่มลูกค้าได้ถึงขีดจำกัดของแพ็คเกจที่เลือกไว้เท่านั้น
- เมื่อใกล้เต็ม หน้าลูกค้าจะขึ้นแถบ **"ใกล้ถึงขีดจำกัดแล้ว (X/Y) อัปเกรดเพื่อเพิ่มลูกค้า"**
- เมื่อเต็มแล้ว จะเพิ่มลูกค้าใหม่ไม่ได้ทุกช่องทาง — ปุ่มเพิ่มลูกค้า ผู้ช่วย AI แอป AI ที่เชื่อมต่อ และการนำเข้าไฟล์ แต่ยัง **แก้ไขและลบ** ลูกค้าเดิมได้ตามปกติ

:::tip[ลูกค้าเต็มแล้วทำอย่างไรดี]
อัปเกรดแพ็คเกจ เปิดเลือกแพ็คเกจอัตโนมัติ หรือลบลูกค้าที่ไม่ได้ใช้แล้ว เลือกทางที่สบายใจที่สุดได้เลย 💡
:::

## ระบบหักพอยต์รายวัน

- ทุกวันระบบจะหักพอยต์ตามราคาแพ็คเกจที่ใช้ — ดูรายการ "ค่าบริการรายวัน" ได้ที่ [ประวัติพอยต์](/package/billing/)
- ถ้ายอดเงินต่ำกว่าราคาแพ็คเกจรายวัน ทั้งแอปจะเข้าสู่โหมดดูอย่างเดียว — ขึ้นแถบเตือน **"ยอดเงินไม่เพียงพอ — ไม่สามารถเพิ่มข้อมูลใหม่ได้"** พร้อมปุ่ม "เติมเงิน" บนทุกหน้าจนกว่าจะเติมเงิน

:::tip[เคล็ดลับ]
เปิด "เลือกแพ็คเกจอัตโนมัติ" ไว้จะสบายใจที่สุด — จ่ายเท่าที่ใช้จริง ลูกค้าลดลง ค่าใช้งานก็ถูกลงเอง 💡
:::
