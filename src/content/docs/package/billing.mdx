## ดูประวัติรายการ

ไปที่ **ตั้งค่า → ประวัติพอยต์** (หัวหน้าเขียนว่า "ประวัติรายการ") เลื่อนดูย้อนหลังได้เรื่อย ๆ

แต่ละรายการแสดง:

- วันที่ (แบบไทย) + ป้ายประเภท + คำอธิบายสั้น ๆ
- จำนวนที่เปลี่ยน: **+X Point** (เขียว) หรือ **−X Point** (แดง)
- ยอดก่อน → หลังทำรายการ เช่น "1,240 → 1,090 Point" — เทียบยอดย้อนหลังได้ทุกรายการ

ถ้ายังไม่มีรายการ จะขึ้น "ยังไม่มีประวัติรายการ"

## ป้ายประเภทรายการ

| ป้าย                   | ความหมาย                                  |
| ---------------------- | ----------------------------------------- |
| **เติมเงิน**            | เติมพอยต์เข้าบัญชี                         |
| **ค่าบริการรายวัน**      | ค่าใช้งานแพ็คเกจที่หักอัตโนมัติทุกวัน         |
| **ใช้งาน AI**           | ค่าใช้ผู้ช่วย AI (คิดตามงานจริงแต่ละครั้ง)     |
| **รางวัลแนะนำ**          | พอยต์ที่ได้จากการชวนเพื่อนเติมเงิน            |
| **โบนัส Team Code**      | +300 Point จากการใช้ทีมโค้ดของเพื่อน          |
| **เครดิตสมัครสมาชิก**    | พอยต์เริ่มต้นฟรีที่ได้ตอนสมัคร                |
| **ปรับยอด**             | ยอดที่ผู้ดูแลระบบปรับให้                     |

## ใบเสร็จ

ใบเสร็จอยู่ต่างหน้า — ไปที่หน้า [เติมเงิน](/package/payment/) ส่วน "ประวัติการชำระเงิน" แล้วกดปุ่ม **"ใบเสร็จ"** ที่รายการที่ชำระสำเร็จ (ตั้งข้อมูลบนใบเสร็จได้ที่ [ตั้งค่าใบเสร็จ](/settings/receipt/))

:::tip[เคล็ดลับ]
เช็คหน้านี้สัปดาห์ละครั้ง — ดูว่ายอดคงเหลือเพียงพอกับค่าบริการรายวันไหม ถ้าเริ่มต่ำให้เติมล่วงหน้า จะได้ไม่เข้าโหมดดูอย่างเดียว 💡
:::
