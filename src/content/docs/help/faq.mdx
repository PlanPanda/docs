---

มีคำถาม? หน้านี้รวบรวมข้อความและสถานการณ์ที่เจอบ่อยพร้อมวิธีจัดการ ลองค้นด้วยข้อความที่เห็นบนหน้าจอดูนะ 😊

## เข้าสู่ระบบและบัญชี

| อาการ / ข้อความ | หมายความว่า | ทางแก้ |
|---|---|---|
| "อีเมลหรือรหัสผ่านไม่ถูกต้อง" | อีเมลหรือรหัสผ่านผิด (ระบบแจ้งข้อความเดียวกันทั้งสองเคสเพื่อความปลอดภัย) | ตรวจสะกดอีเมล ลองรหัสผ่านอีกครั้ง หรือใช้ลิงก์ **ลืมรหัสผ่าน?** ด้านล่างฟอร์ม |
| ลืมรหัสผ่าน | — | หน้าลืมรหัสผ่านจะแจ้ง *"หากอีเมลนี้ลงทะเบียนในระบบ คุณจะได้รับลิงก์รีเซ็ตรหัสผ่าน"* — เช็กอีเมลและกดลิงก์ตั้งรหัสใหม่ |
| "กรุณายืนยันอีเมลก่อนใช้งาน" | ยังไม่ได้กดลิงก์ยืนยันในอีเมล | เปิดอีเมลที่ได้รับตอนสมัคร (เช็กสแปมด้วย) ลิงก์หมดอายุใน 24 ชั่วโมง — กด **ส่งอีเมลยืนยันอีกครั้ง** ได้ |
| "อีเมลนี้มีในระบบแล้ว" ตอนสมัคร | มีบัญชีนี้อยู่แล้ว | เข้าสู่ระบบแทน หรือกด **ลืมรหัสผ่าน** |
| "รหัสผ่านปัจจุบันไม่ถูกต้อง" ตอนเปลี่ยนรหัสผ่าน | รหัสผ่านเดิมที่กรอกผิด | ลองใหม่ ถ้าลืมจริง ใช้ลิงก์ลืมรหัสผ่านหลังออกจากระบบ |

## แพ็คเกจและยอดเงิน

| อาการ / ข้อความ | หมายความว่า | ทางแก้ |
|---|---|---|
| แถบเหลือง "ยอดเงินไม่เพียงพอ — ไม่สามารถเพิ่มข้อมูลใหม่ได้" | ยอดเงินต่ำกว่าค่าแพ็คเกจรายวัน แอปเข้าโหมดดูอย่างเดียว | กด **เติมเงิน** บนแถบ เติมแล้วใช้ได้ทันที (ดู [เติมเงิน](/package/payment/)) |
| "ยอดคงเหลือไม่เพียงพอ" ตอนคุยกับผู้ช่วย AI | Point หมดสำหรับงานนั้น | เติมเงินเพื่อรับ Point — ดู [ประวัติพอยต์](/package/billing/) |
| เปลี่ยนแพ็คเกจได้ไหม | สลับได้ทันทีที่ **ตั้งค่า → เลือก Package** (ดู [แพ็คเกจ](/package/overview/)) | มีโหมด **เลือกแพ็คเกจอัตโนมัติ** ปรับตามจำนวนลูกค้าให้เอง |

## แนบไฟล์ไม่ผ่าน

| ข้อความ | ทางแก้ |
|---|---|
| "ไฟล์ PDF ใหญ่เกิน 20 MB" / "ไฟล์รูปภาพใหญ่เกิน 10 MB" / "ไฟล์ Excel ใหญ่เกิน 5 MB" / "ไฟล์ Word/PowerPoint ใหญ่เกิน 10 MB" | บีบอัดหรือส่งออกใหม่ให้เล็กกว่าขีดจำกัด |
| "แนบไฟล์ได้ไม่เกิน 4 ไฟล์ต่อข้อความ" | ส่งเป็น 2 ข้อความ |
| "รองรับรูปภาพ (JPG, PNG, WebP), PDF, Excel, Word และ PowerPoint" | ชนิดไฟล์ไม่ตรง — แปลงไฟล์ก่อนแนบ |
| "อัปโหลดไม่สำเร็จ ลองอีกครั้ง" | เน็ตกระตุก — ลองแนบใหม่ |

## ผู้ช่วย AI

| อาการ / ข้อความ | หมายความว่า | ทางแก้ |
|---|---|---|
| "คำขอมากเกินไป" | ถามติดกันเร็วเกินไป | รอสักครู่แล้วลองใหม่ |
| "ไม่มีการเชื่อมต่ออินเทอร์เน็ต" | เน็ตหลุดชั่วขณะ | เชื่อมเน็ตแล้วใช้ต่อได้เลย |
| "คำตอบอาจยังไม่ครบ" / "หยุดก่อนเสร็จ" | การเชื่อมต่อหลุดกลางทาง ตอบมาไม่จบ | กด **ลองอีกครั้ง** |
| "รุ่น AI ที่เลือกไม่รองรับรูปภาพ" | รุ่นที่เลือกไว้รับรูปไม่ได้ | เปลี่ยนเป็น **อัตโนมัติ** หรือเลือกรุ่นอื่นที่ **เลือกรุ่น AI** |
| การ์ดยืนยันหายไป | พิมพ์ข้อความใหม่จนการ์ดเก่าถูกยกเลิก | ขอให้ AI ทำรายการนั้นใหม่ได้เลย (ดู [ผู้ช่วย AI](/ai/assistant/)) |
| ลบสนทนา | ระบบถาม "ลบสนทนานี้?" — ลบถาวรพร้อมไฟล์แนบ ย้อนไม่ได้ | คิดดีก่อนกด (แต่กังวลน้อยลงได้ ถ้าข้อมูลจริงยังอยู่ในหน้าลูกค้า) |

## ลูกค้าและกรมธรรม์

| อาการ / ข้อความ | หมายความว่า | ทางแก้ |
|---|---|---|
| "มีชื่อเรียกนี้อยู่แล้ว" ตอนเพิ่มลูกค้า | มีชื่อเรียกซ้ำในระบบ (เตือนเฉย ๆ ไม่บล็อก) | ตรวจว่าไม่ใช่คนเดิมก่อนบันทึก ใช้ชื่อเรียกที่ต่างกัน เช่น เติมนามสกุล (ดู [เพิ่มลูกค้า](/customers/add/)) |
| "กรุณากรอกชื่อกิจกรรม" | ชื่อกิจกรรมจำเป็น | ใส่ชื่อสั้น ๆ แล้วบันทึกได้ (ดู [กิจกรรม](/customers/activities/)) |
| "กรุณาระบุเบี้ยประกันและทุนชีวิตก่อนสร้างแถวรายปี" | ตารางรายปีต้องมีทุนและเบี้ยก่อน | กรอก **ทุนประกันชีวิต** และ **เบี้ยประกัน** ก่อนแล้วค่อยเพิ่มแถว (ดู [กรมธรรม์](/customers/policies/)) |
| "วันที่เริ่มต้องไม่เกินวันที่สิ้นสุด" / "รูปแบบวันที่ไม่ถูกต้อง (วว/ดด/ปปปป พ.ศ.)" | กรอกวันที่ไม่ตรงรูปแบบหรือสลับลำดับ | ใช้ปุ่มปฏิทินช่วยเลือก วันเริ่มต้องมาก่อนวันสิ้นสุด |

## เพิ่มเพื่อน

| ข้อความ | หมายความว่า | ทางแก้ |
|---|---|---|
| "ส่งคำขอไปแล้ว" | คำขอเดิมยังรอเพื่อนตอบอยู่ | รออีกฝ่ายยอมรับ ส่งซ้ำไม่ได้จนกว่าจะถูกปฏิเสธ (ดู [เพิ่มเพื่อน](/team/add-friend/)) |
| "ไม่พบ Team Code นี้" | ทีมโค้ดผิดหรือเว้นวรรคเกิน | ตรวจสะกดให้ตรงรูปแบบ SP-XXXXXXXX |
| "ไม่สามารถเพิ่มตัวเอง" | นั่นคือทีมโค้ดของคุณเอง | ขอโค้ดจากเพื่อนแทน 😄 |

ไม่เจอคำถามที่ต้องการ? ลองถาม **ผู้ช่วย AI** ดูก่อน หรือแจ้งผู้ดูแลระบบของคุณได้เลย — ไม่มีใครรู้ทุกอย่างตั้งแต่วันแรก ✨
