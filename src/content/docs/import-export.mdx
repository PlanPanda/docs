## ส่งออกข้อมูล

อยู่ที่ **ตั้งค่า → ส่งออกข้อมูล** หน้าส่งออกแสดงสรุปจำนวนข้อมูลของคุณ (ลูกค้า / กิจกรรม / ยอดขาย) พร้อมปุ่มดาวน์โหลดให้แต่ละประเภท:

- **JSON** — ไฟล์เดียวรวมข้อมูลครบ เหมาะสำหรับสำรอง หรือนำกลับเข้าระบบ (มีปุ่ม "ดาวน์โหลดรวมทั้งหมด" ให้ด้วย)
- **CSV** — เปิดใน Excel/Google Sheets ได้เลย เหมาะกับการทำ Pivot Table วิเคราะห์ต่อ

### เอาข้อมูลไปให้ AI วิเคราะห์ต่อ

ส่วนล่างของหน้ามี **"คำอธิบายแต่ละ Field"** — อธิบายทุกคอลัมน์ของไฟล์ที่ export:

1. กด **"คัดลอก"** คำอธิบายทั้งหมด
2. ดาวน์โหลดไฟล์ JSON/CSV ที่ต้องการ
3. ไปที่ ChatGPT/Gemini แล้ววางคำอธิบายพร้อมแนบข้อมูล — เช่น "นี่คือข้อมูลลูกค้าของฉันและคำอธิบายแต่ละ field ช่วยสรุปว่าลูกค้ากลุ่มไหนควรตามก่อน"
4. AI จะเข้าใจโครงสร้างข้อมูลถูกต้องทันที

ดูวิธีแบบละเอียดที่ [ใช้ AI ช่วยวิเคราะห์ข้อมูล](/export-ai/)

## นำเข้าข้อมูล

อยู่ที่ **ตั้งค่า → นำเข้าข้อมูล** หน้านำเข้ามี 2 แท็บ:

### แท็บ "เตรียมข้อมูล" — รู้จัก format ที่ระบบต้องการ

- **JSON** (แนะนำ) — นำเข้าลูกค้า + กิจกรรม + ยอดขาย พร้อมกันในไฟล์เดียวได้
- **CSV** — ทีละประเภท (เลือกลูกค้า/กิจกรรม/ยอดขาย)
- กด **"ดาวน์โหลดเทมเพลต"** เพื่อดูโครงสร้างที่ถูกต้อง
- หรือกด **"คัดลอก AI Prompt"** ไปวางใน ChatGPT/Gemini พร้อมข้อมูลเดิมของคุณ (Excel, Google Sheets, ข้อความก็ได้) — AI จะแปลงข้อมูลให้ตรง format ที่ระบบรับ แล้วเอาไฟล์ที่ได้มาอัปโหลดต่อ (ดู [ใช้ AI ช่วยนำเข้าข้อมูล](/import-ai/))

:::note[กฎสำคัญ]
ข้อมูลที่มี `id` ระบบจะอัปเดตของเดิม ไม่มี `id` จะสร้างใหม่ — ไฟล์ JSON เชื่อมข้อมูลใหม่หลายอย่างเข้าด้วยกันได้ด้วยรหัสชั่วคราว (เช่น ลูกค้าใหม่ใช้ tempId "c1" แล้วกิจกรรมอ้าง customerId: "c1") ระบบจะผูกให้เองตอนนำเข้า
:::

### แท็บ "นำเข้า" — อัปโหลดและตรวจสอบ

1. เลือก format (JSON/CSV) — ถ้า CSV ให้เลือกประเภทข้อมูลด้วย
2. ลากไฟล์มาวาง หรือคลิกเลือกไฟล์
3. กด **"ตรวจสอบไฟล์"** แล้วอ่านผลก่อนกดนำเข้าเสมอ:

| ผลลัพธ์            | ความหมาย                                            |
| ------------------ | ---------------------------------------------------- |
| **ตรวจสอบผ่าน**     | พร้อมนำเข้า แสดงสรุปจำนวนที่จะสร้าง/แก้ไข                |
| **ข้อควรระวัง**      | มีข้อมูลซ้ำหรือน่าสงสัย แต่ยังนำเข้าได้                   |
| **พบข้อผิดพลาด**    | ไฟล์มี field ผิด หรือข้อมูลไม่ครบ ต้องแก้ไขก่อน            |

4. ผ่านแล้วกด **"เริ่มนำเข้าข้อมูล"** — ระบบแจ้งสรุปเมื่อเสร็จ

:::tip[เคล็ดลับ]
- นำเข้า **ลูกค้าก่อนเสมอ** แล้วค่อยนำเข้ากิจกรรมและยอดขาย — เพราะสองอย่างหลังต้องเชื่อมกับลูกค้า
- ถ้าผลตรวจมีข้อผิดพลาดหลายรายการ แก้ไฟล์ต้นฉบับแล้วอัปโหลดใหม่ ดีกว่ากดนำเข้าซ้ำ
- ส่งออก JSON เป็นประจำเป็นการสำรองข้อมูลที่ดีที่สุด — วันหนึ่งถ้าต้องย้ายระบบจะไม่เสียข้อมูล
- อยากเอากรมธรรม์เข้าระบบ ใช้ [ผู้ช่วย AI สร้างกรมธรรม์จากไฟล์](/ai/policy-from-file/) อ่านจากรูป/PDF ได้เลย 💡
:::
