อยากสำรองข้อมูล แก้ข้อมูลลูกค้าหลายคนพร้อมกัน หรือย้ายข้อมูลเดิมเข้าระบบ? ใช้ไฟล์ JSON ไฟล์เดียว แยกเป็นสองหน้าตามงาน — ข้อมูลของคุณเป็นของคุณเสมอ 😊

| อยากทำอะไร                                              | ไปที่                     |
| ------------------------------------------------------- | ------------------------ |
| ดาวน์โหลดข้อมูลไปสำรอง แก้ไข หรือให้ AI วิเคราะห์          | **ตั้งค่า → ส่งออกข้อมูล** |
| เพิ่มหรือแก้ลูกค้าจากไฟล์ เช่น ย้ายจาก Excel หรือ Google Sheets | **ตั้งค่า → นำเข้าข้อมูล** |

## ส่งออกข้อมูล

<Screenshot
	name="import-export/export-screen"
	alt="หน้าส่งออกข้อมูลแสดงจำนวนลูกค้า กิจกรรม ยอดขาย กรมธรรม์ เอกสาร พร้อมปุ่มดาวน์โหลด JSON"
	spec="เปิดหน้า ตั้งค่า → ส่งออกข้อมูล ให้เห็นจำนวนข้อมูลทั้ง 5 ประเภท ปุ่ม 'ดาวน์โหลด JSON' (ขั้น 1) และขั้น 2 'ให้ AI ช่วยวิเคราะห์' ในจอเดียว"
/>

### 1. ดาวน์โหลดข้อมูล

หน้านี้แสดงจำนวนลูกค้า กิจกรรม ยอดขาย กรมธรรม์ และเอกสารที่จะอยู่ในไฟล์ กด **ดาวน์โหลด JSON** เพื่อรับไฟล์

- ข้อมูลจัดกลุ่มตามลูกค้า — ใต้ลูกค้าแต่ละคนมีกิจกรรม ยอดขาย กรมธรรม์ (พร้อมสัญญาเพิ่มเติมและตารางมูลค่ารายปี) รูปโปรไฟล์ และเอกสาร
- รูปและเอกสารอยู่ในไฟล์เป็น **ID** เท่านั้น ไม่รวมตัวไฟล์
- ถ้ามีข้อมูลที่ไม่อยู่ในไฟล์ หน้าจอจะแสดง **ข้อมูลบางส่วนไม่อยู่ในไฟล์** แยกตามเหตุผล เช่น "ยอดขาย 3 รายการไม่ผูกกับลูกค้า หรือลูกค้าถูกลบแล้ว จึงไม่อยู่ในไฟล์" ส่วนในไฟล์มีรายการพร้อม ID อยู่ใน `warnings`

### 2. ให้ AI ช่วยวิเคราะห์

กด **คำอธิบายไฟล์ เพื่อให้ AI เข้าใจ** แล้วแนบไปพร้อมไฟล์ข้อมูล — ดูวิธีแบบละเอียดที่ [ใช้ AI ช่วยวิเคราะห์ข้อมูล](/export-ai/)

:::note[ไม่มีไฟล์ CSV แล้ว]
ระบบเหลือแค่ไฟล์ JSON ไฟล์เดียว ไม่มี CSV และการดาวน์โหลดแยกตามประเภทแล้ว ถ้าอยากเปิดใน Excel ให้ AI ช่วยแปลงได้เลย
:::

## นำเข้าข้อมูล

<Screenshot
	name="import-export/import-screen"
	alt="หน้านำเข้าข้อมูล ขั้นเตรียมไฟล์และกรอบลากไฟล์ JSON มาวาง"
	spec="เปิดหน้า ตั้งค่า → นำเข้าข้อมูล ก่อนวางไฟล์ ให้เห็นขั้น 1 'เตรียมไฟล์' (ปุ่มคำอธิบาย / ดาวน์โหลดตัวอย่าง / JSON Schema) และกรอบลากไฟล์มาวาง"
/>

ไฟล์เดียวจะมีลูกค้า 1 คนหรือหลายร้อยคนก็ได้ ขั้นตอนเหมือนกันทุกครั้ง

### 1. เตรียมไฟล์

- **คำอธิบาย เพื่อให้ AI สร้างไฟล์ได้ถูกต้อง** — คัดลอกไปให้ AI พร้อมข้อมูลของคุณ ดู [ใช้ AI ช่วยนำเข้าข้อมูล](/import-ai/)
- **ดาวน์โหลดตัวอย่าง** และ **JSON Schema** — สำหรับคนที่อยากสร้างหรือตรวจไฟล์เอง
- ถ้าจะแก้ลูกค้าเดิม ให้ **ส่งออกก่อน** แล้วแก้ไฟล์นั้น เพราะต้องใช้ `id` จากไฟล์ส่งออก

| ในไฟล์                              | ผลตอนนำเข้า                              |
| ----------------------------------- | ---------------------------------------- |
| ลูกค้ามี `id`                         | แก้ลูกค้าคนเดิม                            |
| ลูกค้าไม่มี `id`                       | สร้างลูกค้าใหม่ **ทุกครั้ง** ที่กดยืนยัน       |
| ไม่ใส่ field                          | ค่าเดิมไม่เปลี่ยน                            |
| ใส่ `null`                           | ล้างค่านั้น                                 |
| ลบลูกค้าคนไหนออกจากไฟล์               | ลูกค้าคนนั้นไม่ถูกแตะ (ไม่ได้ลบ)              |
| ใส่ `riders` หรือ `cashValueRows`     | แทนที่รายการเดิมทั้งหมด `[]` คือล้าง          |
| เอกสารที่มีแค่ `url`                   | เพิ่มเอกสารใหม่ทุกครั้งที่ยืนยัน                |

ID ใช้ได้กับบัญชีที่ส่งออกเท่านั้น ถ้าเอาไฟล์จากบัญชีอื่นมาใช้ ระบบจะแจ้งว่าไม่พบลูกค้าตาม ID

### 2. อัปโหลดและตรวจสอบ

ลากไฟล์ `.json` มาวางในกรอบ หรือคลิกเพื่อเลือก ระบบตรวจทันทีที่ได้ไฟล์ แล้วแสดง:

- บรรทัดสรุป: ลูกค้ากี่คน สร้างใหม่กี่คน อัปเดตกี่คน ผ่านกี่คน มีข้อผิดพลาดหรือคำเตือนกี่คน
- รายชื่อลูกค้าครั้งละ 5 คน คนที่มีปัญหาขึ้นก่อน กด **แสดงเพิ่ม** เพื่อดูต่อ
- ของลูกค้าแต่ละคน: กิจกรรม ยอดขาย กรมธรรม์ และเอกสารที่จะสร้างหรือแก้ ข้อผิดพลาดพร้อมตำแหน่ง (เช่น `customers[3].files.2.url`) คำเตือนเช่นชื่อเรียกหรือเบอร์โทรซ้ำ สัญญาเพิ่มเติมหรือปีกรมธรรม์ที่จะถูกลบ และจำนวนไฟล์ที่จะดาวน์โหลดจาก URL

<Screenshot
	name="import-export/import-preview"
	alt="ผลตรวจไฟล์นำเข้า แสดงบรรทัดสรุปและรายชื่อลูกค้าพร้อมคำเตือน"
	spec="วางไฟล์ตัวอย่างที่มีทั้งลูกค้าใหม่และลูกค้าเดิม (มี id) และมีคำเตือนชื่อเรียกซ้ำอย่างน้อย 1 คน ให้เห็นบรรทัดสรุป รายชื่อลูกค้า 5 คนแรก และปุ่ม 'ยืนยันนำเข้า'"
/>

วางได้ครั้งละ 1 ไฟล์ และรับเฉพาะ `.json` อยากใช้ไฟล์อื่นกด **เปลี่ยนไฟล์** ผลตรวจเดิมจะถูกล้าง

#### เมื่อกดนำเข้าไม่ได้

ระบบแสดงเหตุผลไว้ด้านบนผลตรวจ พร้อมบอกว่าต้องทำอะไรต่อ

| ข้อความ                                                           | ทำอย่างไร                                                                                                                                    |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **ไฟล์นี้จะสร้างลูกค้าใหม่ … คน แต่แพ็คเกจของคุณเพิ่มได้อีก … คน** | (เฉพาะบัญชีที่ปิดเลือกแพ็คเกจอัตโนมัติ) ลดลูกค้าใหม่ในไฟล์ หรือกด **อัปเกรดแพ็คเกจ** แล้ววางไฟล์อีกครั้ง ระบบไม่นำเข้าแค่บางส่วน ลูกค้าที่มี `id` (แก้ไข) ไม่นับ |
| **ยอดเงินไม่พอ บัญชีอยู่ในโหมดดูอย่างเดียว**                      | ยังตรวจไฟล์ได้ตามปกติ กด **เติมเงิน** แล้วจึงนำเข้า                                                                                              |
| **มีข้อผิดพลาด … จุด**                                            | แก้ไฟล์ตามข้อผิดพลาดที่แสดง แล้ววางไฟล์ใหม่                                                                                                       |

#### ถ้าเปิดเลือกแพ็คเกจอัตโนมัติไว้

ระบบไม่ห้ามนำเข้า แต่จะปรับแพ็คเกจขึ้นให้เองตามจำนวนลูกค้า ถ้าไฟล์นี้ทำให้แพ็คเกจเปลี่ยน หน้าจอจะบอกก่อนว่าจะเปลี่ยนจากแพ็คเกจไหนเป็นแพ็คเกจไหน และราคาต่อวันเท่าไร ถ้าไม่ต้องการ ให้ปิด **เลือกแพ็คเกจอัตโนมัติ** ที่ **ตั้งค่า → เลือก Package** ก่อนกดยืนยัน (ดู [ขีดจำกัดจำนวนลูกค้า](/package/overview/#ขีดจำกัดจำนวนลูกค้า))

### 3. ยืนยันนำเข้า

กด **ยืนยันนำเข้า** ระบบบันทึกทีละลูกค้าตามลำดับในไฟล์ ถ้าสำเร็จทั้งหมดจะมีลิงก์ **ดูรายชื่อลูกค้า**

| สถานะ          | ความหมาย                                                                |
| -------------- | ----------------------------------------------------------------------- |
| **สำเร็จ**      | บันทึกแล้ว                                                                |
| **ล้มเหลว**     | ลูกค้าคนนี้ไม่ถูกบันทึกเลย ระบบบอก field หรือไฟล์ที่มีปัญหา เช่น `files.2.url` |
| **ยังไม่เริ่ม**   | ระบบหยุดก่อนถึงคนนี้                                                      |

#### ถ้ามีรายการล้มเหลว

1. กด **ดาวน์โหลดไฟล์ที่เหลือ** — ได้ไฟล์ที่มีเฉพาะรายการที่ล้มเหลวและยังไม่เริ่ม
2. แก้รายการที่ล้มเหลว ถ้าปัญหาเป็นไฟล์แนบ จะแก้ URL หรือลบรายการไฟล์นั้นออกก็ได้ (รูปและเอกสารเดิมยังอยู่)
3. วางไฟล์นั้นแล้วยืนยันอีกครั้ง

<Screenshot
	name="import-export/import-result"
	alt="ผลการนำเข้าแสดงสถานะสำเร็จ ล้มเหลว ยังไม่เริ่ม พร้อมปุ่มดาวน์โหลดไฟล์ที่เหลือ"
	spec="นำเข้าไฟล์ที่มีลูกค้าอย่างน้อย 1 คนแนบไฟล์ด้วย URL ที่เปิดไม่ได้ ให้เห็นสถานะ 'ล้มเหลว' พร้อมตำแหน่ง field และปุ่ม 'ดาวน์โหลดไฟล์ที่เหลือ'"
/>

:::caution[อย่าอัปโหลดไฟล์เดิมทั้งไฟล์ซ้ำ]
ลูกค้าที่ไม่มี `id` และบันทึกสำเร็จไปแล้วจะถูกสร้างซ้ำ — ถ้าหน้าจอไม่แสดงผลการนำเข้า (เช่น เน็ตหลุด) บางรายการอาจบันทึกแล้ว ตรวจรายชื่อลูกค้าก่อนอัปโหลดใหม่
:::

:::tip[เคล็ดลับ]
- ไฟล์ที่ระบบไม่รองรับ (CSV ไฟล์ส่งออกรูปแบบเดิม หรือ `schemaVersion` อื่น) ระบบจะแจ้งให้ใช้ไฟล์รูปแบบใหม่
- ส่งออกเป็นประจำ เป็นการสำรองข้อมูลที่ง่ายที่สุด
- ความสัมพันธ์ระหว่างลูกค้า (ครอบครัว ผู้แนะนำ) ตั้งในหน้าลูกค้า การนำเข้าไม่เปลี่ยนค่าที่ตั้งไว้
- อยากเอากรมธรรม์จากรูปหรือ PDF เข้าระบบ ใช้ [ผู้ช่วย AI สร้างกรมธรรม์จากไฟล์](/ai/policy-from-file/) 💡
:::
