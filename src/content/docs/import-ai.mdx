มีข้อมูลลูกค้าอยู่ใน Excel, Google Sheets หรือโน้ตในมือถือ? ไม่ต้องพิมพ์ใหม่ทีละคน ให้ AI แปลงเป็นไฟล์ JSON แล้วอัปโหลดเข้า SolidPlan ได้เลย 😊

## สิ่งที่เราเตรียมให้แล้ว

ที่ **ตั้งค่า → นำเข้าข้อมูล** ขั้น **1 เตรียมไฟล์** มี:

- **คำอธิบาย เพื่อให้ AI สร้างไฟล์ได้ถูกต้อง** — เปิดหน้าต่างที่อธิบายโครงสร้างไฟล์ กติกาการสร้างและแก้ไข field ทุกตัวพร้อมความหมายและเงื่อนไขตอนนำเข้า ค่าจากระบบ (แท็ก ความต้องการประกัน ความสนใจ) ตัวอย่าง และข้อกำหนดของไฟล์ที่นำเข้าได้ กด **คัดลอก** หรือ **ดาวน์โหลด** (`solidplan-data-v1-import-guide.md`)
- **ดาวน์โหลดตัวอย่าง** — ไฟล์ตัวอย่างลูกค้าใหม่ 1 คน พร้อมกิจกรรม ยอดขาย และกรมธรรม์
- **JSON Schema** — โครงสร้างไฟล์แบบเต็ม สำหรับคนที่อยากตรวจเอง

คำอธิบายนี้บอกแค่ว่าไฟล์ต้องเป็นแบบไหน ไม่ได้สั่ง AI ว่าต้องทำอะไร — คุณเป็นคนบอก AI เองว่าอยากให้ช่วยอะไร

## ขั้นตอน

1. กด **คำอธิบาย เพื่อให้ AI สร้างไฟล์ได้ถูกต้อง** แล้วกด **คัดลอก** (หรือ **ดาวน์โหลด** เป็นไฟล์ `.md` เพื่อแนบ)
2. เปิด ChatGPT / Gemini / Claude วางคำอธิบาย แนบข้อมูลของคุณ แล้วพิมพ์บอกสิ่งที่อยากได้ (ดูตัวอย่างข้อความด้านล่าง)
3. บันทึกคำตอบของ AI เป็นไฟล์ `.json`
4. กลับมาที่หน้า **นำเข้าข้อมูล** ลากไฟล์มาวาง ระบบตรวจให้ทันที แล้วกด **ยืนยันนำเข้า** (ดูรายละเอียดที่ [ย้ายข้อมูลเข้า-ออก](/import-export/#นำเข้าข้อมูล))

:::note[ไม่ต้องกลัวผิด]
ระบบตรวจก่อนบันทึกเสมอ ถ้าผิดจะบอก field ที่ต้องแก้
:::

## ตัวอย่างข้อความถาม AI

พิมพ์ต่อท้ายคำอธิบายที่คัดลอกมา เลือกแบบที่ตรงกับงานของคุณ

- **ย้ายจาก Excel / Google Sheets:** "นี่คือรายชื่อลูกค้าจาก Excel ช่วยแปลงเป็นไฟล์ JSON ตามคำอธิบายด้านบน ตอบเป็น JSON อย่างเดียว ถ้าแถวไหนแปลงไม่ได้ให้แจ้งแยกหลัง JSON"
- **จากโน้ตในมือถือ:** "นี่คือโน้ตลูกค้าของฉัน ช่วยสร้างไฟล์ JSON ที่มีลูกค้า กิจกรรม และยอดขายตามคำอธิบาย ใส่เฉพาะข้อมูลที่มีในโน้ต ห้ามเดาค่า"
- **แก้ลูกค้าเดิม:** "นี่คือไฟล์ที่ส่งออกจาก SolidPlan ช่วยเปลี่ยนสถานะลูกค้าที่ซื้อแล้วเป็น customer เก็บ id เดิมไว้ทุกคน และตัดลูกค้าที่ไม่ได้แก้ออกจากไฟล์"
- **ตรวจไฟล์ก่อนนำเข้า:** "ช่วยตรวจไฟล์ JSON นี้ตามข้อกำหนดของไฟล์ที่นำเข้าได้ในคำอธิบาย แล้วบอกจุดที่ต้องแก้"

## ตัวอย่าง: จากโน้ตสู่ SolidPlan

```
โน้ต: "วิภา ใจดี 089-123-4567 เพื่อนสมัยเรียน คุยแผนสุขภาพ 1 พ.ย. ปิดได้ 25,000"

    ↓ คำอธิบาย + โน้ต + ข้อความถาม → AI

{
  "schemaVersion": 1,
  "customers": [
    {
      "firstName": "วิภา",
      "lastName": "ใจดี",
      "phone": "0891234567",
      "relation": "friend",
      "activities": [
        { "tempId": "meeting-1", "name": "คุยแผนประกันสุขภาพ", "contactDate": "2026-11-01T10:00:00+07:00" }
      ],
      "salesRecords": [
        { "activityTempId": "meeting-1", "policyName": "ประกันสุขภาพ", "amount": 25000, "soldDate": "2026-11-01" }
      ]
    }
  ]
}
```

กิจกรรม ยอดขาย และกรมธรรม์อยู่ใต้ลูกค้าคนนั้นเลย ไม่ต้องจับคู่ ID เอง — ถ้ายอดขายมาจากกิจกรรมใหม่ในไฟล์เดียวกัน ให้ใส่ `tempId` ที่กิจกรรม และ `activityTempId` ที่ยอดขาย

:::caution[ข้อมูลส่วนบุคคล]
ชื่อ เบอร์โทร วันเกิด และกรมธรรม์ของลูกค้าเป็นข้อมูลส่วนบุคคล ข้อมูลที่ส่งให้ AI อยู่ภายใต้นโยบายความเป็นส่วนตัวของ AI ที่คุณเลือก — ส่งเฉพาะลูกค้าและ field ที่จำเป็น และหลีกเลี่ยงบันทึกที่ไม่เกี่ยวข้อง (ดู [PDPA](/customers/pdpa/))
:::

:::tip[เคล็ดลับ]
- ลูกค้าใหม่ **ไม่ต้องมี `id`** และจะถูกสร้างใหม่ทุกครั้งที่ยืนยัน — อัปโหลดไฟล์เดิมสองครั้งจะได้ลูกค้าซ้ำ
- อยากให้ AI ช่วยแก้ข้อมูลลูกค้าเดิม ให้ส่งออกที่ **ตั้งค่า → ส่งออกข้อมูล** ก่อน ตัดไฟล์ให้เหลือเฉพาะลูกค้าและ field ที่จะแก้ แล้วส่งให้ AI แก้ — AI ต้องเก็บ `id` เดิมไว้
- ลูกค้าใหม่ทั้งไฟล์ต้องไม่เกินจำนวนที่แพ็คเกจยังเพิ่มได้ ถ้าเกินระบบจะไม่นำเข้าทั้งไฟล์ ให้แบ่งไฟล์หรืออัปเกรดแพ็คเกจ
- ถ้าอยากแนบเอกสาร ใส่ `files` เป็นลิงก์ `https` ที่เปิดได้แบบสาธารณะ ระบบจะดาวน์โหลดตอนยืนยัน
- ถ้ามีบางคนล้มเหลว ใช้ปุ่ม **ดาวน์โหลดไฟล์ที่เหลือ** แก้แล้วอัปโหลดเฉพาะไฟล์นั้น 💡
:::

ลองให้ AI ช่วยแปลงข้อมูลสักครั้ง จะพบว่าเร็วกว่าพิมพ์เองมาก ✨
