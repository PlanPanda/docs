## หน้าจอยอดขาย

หน้านี้แบ่งเป็น 2 ส่วน:

| ส่วน          | แสดง                                                          |
| ------------- | ------------------------------------------------------------- |
| **แผงซ้าย**    | สรุปผลรายปี — เป้าหมาย, ยอดสะสม FYP, ความก้าวหน้า, ยอดรายเดือน     |
| **รายการขวา** | "รายการขาย (N)" ของปีที่เลือก เลื่อนดูได้เรื่อย ๆ                  |

หน้านี้แสดงเฉพาะ **ยอดขายของคุณเอง** (ผลงานของเพื่อนดูได้ที่หน้าทีมงาน มุมมอง "เป้าหมาย")

## สถิติรายปี (แผงซ้าย)

<Screenshot
	name="sales/records-stats"
	alt="แผงสถิติรายปีแสดงเป้าหมาย MDRT/COT/TOT ยอดสะสม FYP แถบความก้าวหน้า และตารางยอดรายเดือน"
	spec="ให้เห็นตัวเลือกสลับระดับเป้าหมาย MDRT/COT/TOT แถบเปอร์เซ็นต์ความก้าวหน้า และตาราง 12 เดือนชัดเจน"
/>

- **เป้าหมาย MDRT/COT/TOT ปี 2569** — เลือกสลับระดับเป้าได้ตรงนี้เลย (ไปตั้งที่หน้าตั้งค่าตัวแทนก็ได้ ค่าเดียวกัน)
- **สะสม FYP** และ **ขาดอีก / เกิน** — ยอดที่นับคือเฉพาะรายการ "อนุมัติแล้ว" ที่วันที่ขายไม่เกินวันนี้
- **ความก้าวหน้า** — แถบเปอร์เซ็นต์เทียบเป้า (เขียวเมื่อใกล้ครบ, ส้มกลาง ๆ, แดงเมื่อยังน้อย)
- **ยอดรายเดือน (FYP)** — ตาราง 12 เดือน พร้อมจำนวนกรมธรรม์ในวงเล็บ เดือนปัจจุบันมีเครื่องหมายกำกับให้เห็น
- **เป้าเดือน (เดือนปัจจุบัน)** — บอกเลยว่าเดือนนี้ "เกิน X ฿ / ขาดอีก X ฿ / ตรงเป้า"

## รายการขาย

<Screenshot
	name="sales/records-list"
	alt="รายการขายแต่ละรายการแสดงลูกค้า ชื่อแพ็คเกจประกัน จำนวนเงิน FYP วันที่ขาย และสถานะอนุมัติ"
	spec="ให้เห็นรายการหลากสถานะ: รออนุมัติ (เหลือง) อนุมัติแล้ว (เขียว) ปฏิเสธ (แดง) และชิป 'บันทึกล่วงหน้า · ยังไม่นับยอดสะสม'"
/>

แต่ละรายการแสดง: ลูกค้า · ชื่อแพ็คเกจประกัน (+ หมายเหตุถ้ามี) · จำนวนเงิน · FYP และเปอร์เซ็นต์ที่นับ · วันที่ขาย (พ.ศ.) · สถานะ — **รออนุมัติ** (เหลือง) / **อนุมัติแล้ว** (เขียว) / **ปฏิเสธ** (แดง) · และชิป **"บันทึกล่วงหน้า · ยังไม่นับยอดสะสม"** ถ้าวันที่ขายอยู่ในอนาคต

## เพิ่มรายการขายใหม่

<Screenshot
	name="sales/records-form"
	alt="ฟอร์มเพิ่มรายการขาย มีฟิลด์ลูกค้า ชื่อแพ็คเกจประกัน จำนวนเงิน เปอร์เซ็นต์นับเป้า วันที่ขาย และหมายเหตุ"
	spec="เปิดฟอร์ม 'เพิ่มรายการขาย' ให้เห็นฟิลด์ครบทุกช่องพร้อมปุ่ม 'เพิ่ม'"
/>

มี 3 จุดเข้า:

1. ปุ่ม **"+ เพิ่มรายการขาย"** ที่หน้ายอดขาย
2. หน้าลูกค้า — เปิดสวิตช์ **"ปิดการขาย"** ที่การ์ดกิจกรรม (ระบบเปิดฟอร์มพร้อมเลือกลูกค้าไว้แล้ว)
3. หน้าปฏิทิน — วิธีเดียวกันกับกิจกรรมบนปฏิทิน

ฟอร์ม "เพิ่มรายการขาย" มีฟิลด์:

| ฟิลด์                    | จำเป็น   | รายละเอียด                                                                                          |
| ------------------------ | -------- | --------------------------------------------------------------------------------------------------- |
| ลูกค้า                    | ✅       | ค้นหาจากรายชื่อลูกค้าของคุณ                                                                              |
| ชื่อแพ็คเกจประกัน            | ✅       | พิมพ์อิสระ เช่น "แบบตลอดชีพ 10 ปี"                                                                       |
| จำนวนเงิน (บาท)            | ✅       | ตัวเลข เช่น 24,000.00                                                                                  |
| นับ MDRT/COT/TOT (%)       | ไม่จำเป็น | ค่าเริ่มต้น 100% — ปรับได้ถ้ารายการนี้ควรนับเข้าเป้าแค่บางส่วน                                                |
| วันที่ขาย                  | ✅       | พิมพ์เป็น พ.ศ. ได้ (วว/ดด/ปปปป) มีปุ่ม "วันนี้" — บันทึกวันอนาคตได้ ระบบจะแจ้งว่ายังไม่นับยอดสะสม                |
| หมายเหตุ                   | ไม่จำเป็น | โน๊ตสั้น ๆ แสดงในรายการ                                                                                  |

กด **"เพิ่ม"** — รายการเข้าสถานะ "รออนุมัติ" และระบบจะสร้างกิจกรรม "ปิดการขาย \{ชื่อแพ็คเกจ\}" ให้ลูกค้าอัตโนมัติ (ถ้าบันทึกจากกิจกรรมที่มีอยู่แล้ว จะผูกกับกิจกรรมนั้นให้เอง)

:::note[สถานะอนุมัติ]
สถานะอนุมัติแก้ได้ในหน้าแก้ไขรายการเท่านั้น — เปลี่ยนเป็น "อนุมัติแล้ว" เมื่อบริษัทอนุมัติจริง ยอดจึงจะเข้าสถิติสะสม
:::

## แก้ไขและลบรายการขาย

- **แก้ไข** — กดไอคอนปากกาที่รายการ → หน้าต่าง "แก้ไขรายการขาย" → บันทึก (หน้านี้จะเห็นฟิลด์ "สถานะอนุมัติ" เพิ่มมาให้)
- **ลบ** — กดปุ่มถังขยะในหน้าแก้ไข → กดอีกครั้งเมื่อขึ้นคำว่า "ยืนยันลบ" → ลบทันที

## สลับปี

ใช้ dropdown "ปี พ.ศ." มุมขวาบนของรายการ — ดูย้อนหลังได้ 4 ปี และปีไหนที่มียอดบันทึกไว้ (รวมปีอนาคตที่บันทึกล่วงหน้า) จะโผล่ในเมนูด้วย

:::tip[เคล็ดลับ]
- บันทึกยอดขายทันทีหลังปิดดีล — ถ้ารอนานอาจลืมจำนวนเบี้ยที่แน่นอน
- ดีลที่ยังไม่อนุมัติก็บันทึกไว้ก่อนได้ (รออนุมัติ) ยอดจะไม่นับจนกว่าจะสลับเป็น "อนุมัติแล้ว"
- กรมธรรม์ฉบับเต็ม (รายละเอียด สัญญาเพิ่มเติม ตารางมูลค่าเวนคืนรายปี) จัดเก็บแยกไว้ที่แท็บกรมธรรม์ของลูกค้าแต่ละคนใน [หน้าลูกค้า](/customers/overview/)
:::

บันทึกยอดขายเป็นนิสัยทุกดีล สิ้นปีจะได้เห็นผลงานของคุณครบทุกรายการ ไม่ตกหล่นแม้แต่ดีลเดียว ✨
