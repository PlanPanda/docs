## ตั้งค่าข้อมูลออกใบเสร็จ

ที่ **ตั้งค่า → ตั้งค่าใบเสร็จ** (หัวฟอร์มเขียนว่า "ข้อมูลสำหรับออกใบเสร็จรับเงิน"):

| ฟิลด์                        | ใช้ทำอะไร                                                     |
| ---------------------------- | ------------------------------------------------------------ |
| **ชื่อบริษัท/ร้าน/บุคคล**       | ชื่อที่แสดงบนใบเสร็จ                                            |
| **ที่อยู่**                   | ที่อยู่สำหรับออกใบเสร็จ                                         |
| **เลขผู้เสียภาษี**             | เลข VAT (ถ้ามี) — จำเป็นสำหรับใบเสร็จที่ถูกต้องตามกฎหมาย             |

กด **"บันทึก"** → จะมีแจ้ง "บันทึกข้อมูลใบเสร็จเรียบร้อย"

## ดาวน์โหลดใบเสร็จ

ใบเสร็จอยู่ที่ตาราง **"ประวัติการชำระเงิน"** ในหน้า [เติมเงิน](/package/payment/):

- รายการที่ชำระ**สำเร็จ**จะมีปุ่ม **"ใบเสร็จ"** → ดาวน์โหลดเป็น PDF ได้ทันที
- ใบเสร็จจะใช้ข้อมูลบริษัทที่คุณตั้งไว้ในหน้านี้

:::tip[เคล็ดลับเล็ก ๆ 💡]
ตั้งค่าข้อมูลใบเสร็จตั้งแต่วันแรก — ไม่ต้องรอจนกว่าจะต้องใช้ เพราะใบเสร็จที่ออกไปแล้วจะไม่ย้อนไปอัปเดตข้อมูลให้
:::

ตั้งค่าครบแล้ว! ไปดูและดาวน์โหลดใบเสร็จของคุณได้ที่ [เติมเงิน](/package/payment/) หรือกลับไปดูภาพรวมที่ [ภาพรวมตั้งค่า](/settings/overview/) ✨
