## แก้ไขข้อมูลส่วนตัว

ที่ **ตั้งค่า → ข้อมูลส่วนตัว**:

| ฟิลด์          | รายละเอียด                                                                                    |
| -------------- | -------------------------------------------------------------------------------------------- |
| รูปโปรไฟล์      | คลิกที่รูปเพื่อเปลี่ยน ("คลิกเพื่อเปลี่ยนรูป") รองรับ JPEG/PNG/WebP — ลบรูปได้ด้วยปุ่ม X                |
| ชื่อ-สกุล       | ชื่อของคุณในระบบ                                                                               |
| ชื่อเรียก       | ชื่อที่เพื่อนเห็นในหน้าทีมงาน                                                                     |
| วันเกิด         | พิมพ์เป็น พ.ศ. ได้ (วว/ดด/ปปปป พ.ศ.) เลือกได้ไม่เกินวันนี้                                            |
| อีเมล          | แสดงอย่างเดียว — "ไม่สามารถเปลี่ยนอีเมลได้"                                                        |
| เบอร์โทร       | เบอร์ติดต่อของคุณ                                                                               |
| ภาษา           | ไทย / English                                                                                  |

:::note[บันทึกอัตโนมัติ]
แก้แล้วระบบบันทึกให้เอง (ช่องพิมพ์จะบันทึกหลังหยุดพิมพ์) ดูสถานะได้จากข้อความ "กำลังบันทึก... / บันทึกแล้ว / บันทึกไม่สำเร็จ" — ไม่ต้องกดปุ่มบันทึก
:::

## เปลี่ยนรหัสผ่าน

เปลี่ยนได้ที่หน้าแยก **ตั้งค่า → เปลี่ยนรหัสผ่าน**:

1. กรอก **รหัสผ่านปัจจุบัน / รหัสผ่านใหม่ / ยืนยันรหัสผ่านใหม่**
2. กด **"เปลี่ยนรหัสผ่าน"** — จะมีแจ้ง "เปลี่ยนรหัสผ่านเรียบร้อย" และยังใช้งานต่อได้ทันที ไม่ต้องเข้าใหม่

ถ้าลืมรหัสผ่านจนเข้าไม่ได้ ใช้ **"ลืมรหัสผ่าน?"** ที่หน้าเข้าสู่ระบบแทน — ดู [เข้าสู่ระบบ](/start/login/) และจัดการทั้งรหัสผ่านและ Google ต่อได้ที่ [วิธีเข้าสู่ระบบ](/settings/auth-methods/)

:::tip[เคล็ดลับเล็ก ๆ 💡]
- เปลี่ยนรหัสผ่านทุก 3-6 เดือน — จำง่ายแต่เดายาก เช่น ชื่อสัตว์เลี้ยง + ตัวเลข + อักษรพิเศษ
- ใส่รูปโปรไฟล์ไว้จะช่วยให้เพื่อนในหน้าทีมงานจำคุณได้ง่ายขึ้น
:::

ข้อมูลส่วนตัวเรียบร้อย → ดูแลความปลอดภัยของบัญชีต่อที่ [วิธีเข้าสู่ระบบ](/settings/auth-methods/) ✨
