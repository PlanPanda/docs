อยากให้ผู้ช่วยงาน AI ของคุณ เช่น ChatGPT หรือ Claude ดึงข้อมูลลูกค้า กิจกรรม นัดหมาย และกรมธรรม์จาก SolidPlan ไปใช้ต่อ — เชื่อมได้ 2 ทาง ผ่าน **API Key** หรือผ่าน **OAuth** และเพิกถอนได้ทุกเมื่อ 😊

## ทางที่ 1: เชื่อมต่อผ่าน Key

เปิด **ตั้งค่า → เชื่อมต่อผ่าน Key** — หน้านี้จัดการ API Key ส่วนตัวของคุณสำหรับต่อแอป AI เข้ากับข้อมูล SolidPlan ผ่านช่องทาง MCP

1. กด **เพิ่ม Key** ตั้ง **ชื่อ Key** ให้จำง่ายและแยกตามเครื่อง เช่น "Claude บน MacBook" — ใช้ Key แยกกันแต่ละอุปกรณ์จะเพิกถอนทีละเครื่องได้ง่าย
2. **บันทึก Key นี้ไว้ตอนนี้** — ระบบแสดง Key เต็ม **เพียงครั้งเดียว** กดคัดลอกเก็บไว้ในแอป AI ของคุณก่อนกด **บันทึกเรียบร้อย** (ถ้าทำหายต้องสร้าง Key ใหม่และเพิกถอน Key เดิม)
3. ก๊อป **URL สำหรับ MCP** จากการ์ดด้านล่างไปวางในการตั้งค่า MCP ของแอป AI พร้อมกับ Key

ข้อควรรู้เรื่อง Key:

- Key เห็นข้อมูลได้ **ตามสิทธิ์ของบัญชีคุณ** และยังจัดการข้อมูลได้แม้แอปอยู่โหมดดูอย่างเดียว
- Key **ไม่มีวันหมดอายุ** — ใช้ได้จนกว่าคุณจะเพิกถอนเอง
- เปลี่ยนชื่อ Key ภายหลังได้ รายการโชว์วันสร้างและวันใช้ล่าสุด ช่วยสังเกต Key แปลกปลอม
- **เพิกถอน** — กดแล้วยืนยันอีกชั้น ("เพิกถอนแล้วกู้คืนไม่ได้ การเชื่อมต่อที่ใช้ Key นี้จะหยุดทันที") Key เก่าจะถูกเก็บไว้ในรายการ "ดู Key ที่เพิกถอนแล้ว" ให้ไล่ตรวจย้อนหลังได้

## ทางที่ 2: เชื่อมต่อผ่าน OAuth

เปิด **ตั้งค่า → เชื่อมต่อผ่าน OAuth** — สำหรับแอป AI ที่รองรับการล็อกอิน เช่น ChatGPT หรือ Claude

1. ในแอป AI นั้น กด **Connect** แล้วเข้าสู่ระบบด้วยบัญชี SolidPlan ของคุณ
2. หน้า **อนุมัติการเชื่อมต่อ** จะบอกว่าแอปไหนขอเข้าถึง พร้อมหัวข้อ **"สิ่งที่จะเข้าถึงได้"** — ข้อมูล CRM ผ่าน MCP (ลูกค้า กิจกรรม นัดหมาย กรมธรรม์) และการเชื่อมต่อต่อเนื่องโดยไม่ต้องอนุมัติซ้ำ กด **อนุมัติ** เมื่อเช็กแล้ว
3. แอปจะปรากฏในรายการพร้อมวันเชื่อมต่อและวันใช้ล่าสุด — กด **เพิกถอน** ได้ทุกเมื่อ การเชื่อมต่อจะตัดทันทีและแอปต้องขออนุมัติใหม่ถ้าจะกลับมา

## ระดับความสามารถ: อ่าน / เขียน / ลบ

สิ่งที่แอป AI เรียกใช้ได้มี 3 ระดับ — **อ่าน** (ค้น/เปิดดูข้อมูล), **เขียน** (เพิ่ม/แก้ข้อมูล, อัปโหลดไฟล์), **ลบ** (ลบลูกค้า กิจกรรม กรมธรรม์)

- ระดับเหล่านี้เป็น **สวิตช์ระดับระบบที่ผู้ดูแลระบบเป็นคนเปิด** — **ค่าเริ่มต้นปิดหมด** และเปิดตามลำดับ อ่าน → เขียน → ลบ (ปิดอ่านเมื่อไหร่ เขียน/ลบปิดตามทันที)
- ผู้ใช้ทั่วไปไม่ได้ตั้งระดับเอง และ Key ก็ไม่ได้แยกระดับรายดอก — ทุก Key ทำงานในกรอบที่ผู้ดูแลเปิดให้
- ฝั่ง "ลบ" จะปลอดภัยเป็นพิเศษ: แอป AI ต้องยืนยันการลบทุกครั้ง และระบบจะโชว์การ์ดยืนยันให้คุณกดอนุมัติก่อนข้อมูลเปลี่ยนเสมอ

:::tip[เคล็ดลับความปลอดภัย 💡]
เช็ก "วันใช้ล่าสุด" ของ Key และแอป OAuth เป็นประจำ — ถ้าเจอรายการที่ไม่ได้ใช้หรือไม่รู้จัก เพิกถอนไว้ก่อน สร้างใหม่ได้เสมอ
:::

เชื่อมต่อเสร็จแล้ว ลองถามแอป AI ของคุณดูว่า "สัปดาห์นี้มีนัดใครบ้าง" — ข้อมูลจะมาตอบในแชทที่คุณคุ้นเคย หรือจะใช้ [ผู้ช่วย AI](/ai/assistant/) ในตัวก็ได้เสมอ ✨
