หมวด **ตั้งค่า** คือศูนย์กลางจัดการทุกอย่างที่เกี่ยวกับบัญชีของคุณ — ตั้งค่าครบสักครั้ง แล้วใช้งานได้ลื่นไหลทุกวัน หน้านี้คือแผนที่นำทางว่าแต่ละหน้าใช้ทำอะไร พร้อมลิงก์เข้าคู่มือทุกหน้า 😊

## หน้าทั้งหมดใน "ตั้งค่า"

| กลุ่ม            | หน้า                                                                                                              | ใช้ทำอะไร                            |
| ---------------- | ----------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| ข้อมูล            | [ข้อมูลส่วนตัว](/settings/profile/)                                                                                  | ชื่อ รูปโปรไฟล์ วันเกิด เบอร์โทร ภาษา        |
| ข้อมูล            | [ข้อมูล Agent](/team/agent-profile/)                                                                                | สถานะ Tier โหมดส่วนตัว ใบรับรอง             |
| ข้อมูล            | [สังกัด](/team/org-hierarchy/)                                                                                      | หน่วยและกลุ่มที่คุณสังกัด                   |
| ข้อมูล            | [โค้ดสร้างทีม](/team/campaign/)                                                                                     | ทีมโค้ดชวนเพื่อนและรางวัล                   |
| แพ็คเกจ          | [เลือก Package](/package/overview/) · [เติมเงิน](/package/payment/) · [ประวัติพอยต์](/package/billing/) · [ตั้งค่าใบเสร็จ](/settings/receipt/) | จัดการแพ็คเกจรายวัน เติมเงิน และใบเสร็จ         |
| AI              | [เชื่อมต่อผ่าน Key / เชื่อมต่อผ่าน OAuth](/settings/ai-connections/)                                                    | ให้แอป AI อื่นเข้าถึงข้อมูลของคุณ              |
| ยืนยันตัวตน       | [เปลี่ยนรหัสผ่าน / วิธีเข้าสู่ระบบ](/settings/auth-methods/)                                                            | จัดการรหัสผ่านและ Google                    |
| ข้อมูลของคุณ       | [นำเข้าข้อมูล / ส่งออกข้อมูล](/import-export/)                                                                          | ย้ายข้อมูลเข้า-ออก                         |

:::tip[เคล็ดลับเล็ก ๆ 💡]
มือใหม่แนะนำไล่จากบนลงล่าง — ตั้งข้อมูลส่วนตัวและวิธีเข้าสู่ระบบก่อน แล้วค่อยตั้งค่าใบเสร็จก่อนเติมเงินครั้งแรก
:::

เลือกหัวข้อจากตารางด้านบนได้เลย หรือเริ่มจากพื้นฐานที่สุดอย่าง [ข้อมูลส่วนตัว](/settings/profile/) ✨
