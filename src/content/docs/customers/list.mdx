## ค้นหาลูกค้า

<Screenshot
	name="customers/list-search"
	alt="ช่องค้นหาด้านบนรายชื่อ พร้อมผลลัพธ์ที่กรองแล้ว"
	spec="พิมพ์คำค้นในช่องค้นหาแล้วให้รายชื่อเหลือเฉพาะลูกค้าที่ตรง พร้อมเห็นปุ่ม X สำหรับล้างการค้นหา"
/>

- พิมพ์**ชื่อ** ที่ช่องค้นหาด้านบน — ระบบค้นทั้งชื่อเรียกและชื่อเต็ม แสดงผลทันทีขณะพิมพ์
- อยากค้นจาก**โน๊ต** เปิดตัวกรองแล้วใช้ช่อง "ค้นหาโน๊ต" แยกต่างหาก
- กด X เพื่อล้างการค้นหาเมื่อไหร่ก็ได้

## กรองรายชื่อ

<Screenshot
	name="customers/list-filters"
	alt="แผงตัวกรองเพิ่มเติมทั้งหมด ทั้งความต้องการประกัน แท็ก ช่วงรายได้ ความสนิท วันเกิด และค้นหาโน๊ต"
	spec="กดไอคอนตัวกรองเพื่อเปิดแผงตัวกรอง ให้เห็นตัวกรองครบทุกหมวดในภาพเดียว"
/>

### กรองตามประเภท

แถวชิปด้านบนรายชื่อแสดงจำนวนสด ๆ เสมอ: **ทั้งหมด (n) / ผู้มุ่งหวัง (n) / ลูกค้า (n)**

### ตัวกรองเพิ่มเติม (กดไอคอนตัวกรองเพื่อเปิด)

| ตัวกรอง | ใช้ทำอะไร |
|---------|-----------|
| **ความต้องการประกัน** | หาคนที่สนใจความคุ้มครองด้านนั้น เช่น สุขภาพ |
| **แท็ก** | เลือกหลายแท็กได้ เช่น "VIP", "กอล์ฟ" (ค้นหาแท็กในเมนูได้ถ้าแท็กเยอะ) |
| **ช่วงรายได้** | เลือกจาก 8 ช่วงรายได้ |
| **ความสนิท** | สนิทมาก (= สนิทรักเรา) / รู้จักพอสมควร / รู้จักแต่ไม่สนิท / ไม่รู้จักเลย |
| **วันเกิด** | วันนี้ / เดือนนี้ / เดือนหน้า หรือ "หรือระบุเอง" เลือกเดือน+วันที่ต้องการ — เหมาะกับหาลูกค้าที่วันเกิดกำลังจะถึง |
| **ค้นหาโน๊ต** | หาจากคำที่จดไว้ เช่น "กอล์ฟ" |

ใช้ตัวกรองร่วมกันได้ — เช่น กรอง "ผู้มุ่งหวัง" + "รายได้สูง" เพื่อหาคนที่น่าจะเป็นลูกค้ารายใหญ่

## เรียงลำดับ

<Screenshot
	name="customers/list-sort"
	alt="ตัวเลือกเรียงลำดับรายชื่อ ชื่อ จำนวนกิจกรรม และกิจกรรมล่าสุด"
	spec="เปิดเมนูเรียงลำดับด้านบนรายชื่อ ให้เห็นตัวเลือกทั้ง 3 แบบและทิศทางการเรียง"
/>

| เรียงตาม | เหมาะเมื่อ |
|---------|-----------|
| **ชื่อ** | หาคนตามตัวอักษร |
| **จำนวนกิจกรรม** | ดูว่าใครถูกดูแลบ่อย/นาน |
| **กิจกรรมล่าสุด** (ค่าเริ่มต้น) | ดูว่าใครเพิ่งถูกติดต่อ ใครนานไม่ได้ติดต่อ |

กดอีกทีเพื่อสลับเรียงจากน้อยไปมาก / มากไปน้อย

## สิ่งที่แสดงบนการ์ดลูกค้าแต่ละใบ

<Screenshot
	name="customers/list-card"
	alt="การ์ดลูกค้าหนึ่งใบขยายให้เห็นองค์ประกอบครบ รูปโปรไฟล์ ชื่อ ความสนิท แท็ก และไอคอนแก้ไข"
	spec="เลือกการ์ดลูกค้าที่มีข้อมูลครบ ทั้งป้าย VIP แท็ก วันเกิด และกรอบเขียวของลูกค้าที่ซื้อแล้ว จะได้เห็นทุกองค์ประกอบในใบเดียว"
/>

- รูปโปรไฟล์ (หรืออักษรย่อ) — กรอบสีเขียว = ลูกค้าที่ซื้อแล้ว
- ชื่อเรียก (ตัวใหญ่) + ชื่อเต็ม (บรรทัดรอง)
- ไอคอนหัวใจแสดงระดับความสนิท
- 🎂 ถ้าวันนี้เป็นวันเกิดของเขา
- ป้าย VIP (ส้ม) หรือแท็ก — ถ้าไม่มีเลยจะแสดงประเภท "ผู้มุ่งหวัง/ลูกค้า" แทน
- โน๊ตย่อ (หรือ "ยังไม่มีบันทึกเพิ่มเติม")
- จุดสีแสดงประวัติกิจกรรมล่าสุด
- ไอคอนปากกา — กดเข้าแก้ไขข้อมูลได้ทันที

:::note[เลื่อนดูได้ไม่อั้น]
รายชื่อเลื่อนดูได้เรื่อย ๆ (เลื่อนถึงไหนระบบโหลดเพิ่มให้ถึงนั่น) ไม่ต้องกดเปลี่ยนหน้า
:::

## ขีดจำกัดลูกค้าตามแพ็คเกจ

- เมื่อจำนวนลูกค้าใกล้ขีดจำกัดของแพ็คเกจ (90% ขึ้นไป) จะมีแถบเตือนสีเหลือง "ใกล้ถึงขีดจำกัดแล้ว (n/max) อัปเกรดเพื่อเพิ่มลูกค้า" กดไปดูแพ็คเกจได้เลย
- ถ้ายอดเงินในบัญชีต่ำกว่าราคาแพ็คเกจรายวัน ปุ่มเพิ่มลูกค้าจะกดไม่ได้ พร้อมข้อความ "ยอดเงินไม่เพียงพอ กรุณาเติมเงิน" — ดูวิธีเติมที่ [เติมเงิน](/package/payment/)

## เคล็ดลับเล็ก ๆ 💡

- ลองเรียงตาม "กิจกรรมล่าสุด" จากน้อยไปมาก — จะเห็นทันทีว่าใครนานไม่ได้ติดต่อ เหมาะกับวันที่อยากไปหาลูกค้าเก่า ๆ
- กรอง "วันเกิด → เดือนหน้า" ทุกต้นเดือน แล้วเตรียม [การ์ดอวยพรวันเกิด](/ai/birthday-card/) ให้ลูกค้าล่วงหน้า
