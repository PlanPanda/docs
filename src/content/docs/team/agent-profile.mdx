## ก่อนเริ่ม

- เปิดเมนู **ตั้งค่า → ข้อมูล Agent**
- ทุกอย่างที่ตั้งที่นี่คือสิ่งที่เพื่อนเห็นบนการ์ดและหน้ารายละเอียดของคุณในหน้าทีมงาน
- แก้แล้วระบบบันทึกอัตโนมัติ (ดูสถานะ "กำลังบันทึก... / บันทึกแล้ว / บันทึกไม่สำเร็จ") — ไม่ต้องกดปุ่มบันทึก

## ข้อมูลที่คุณสามารถตั้งค่าได้

### บริษัทต้นสังกัดและธีมสี

- **บริษัทต้นสังกัด** — เลือกบริษัทประกันที่คุณสังกัด (หรือไม่ระบุก็ได้)
- **ธีมสี** — เลือกสีธีมของแอปได้ตามใจ (มีสีตามบริษัทประกันให้ด้วย) — เลือกบริษัทแล้วอยากใช้สีอื่นต่อได้ เพราะธีมแยกตั้งจากบริษัท

### สถานะ

เลือกสถานะปัจจุบันของคุณ — **Fulltime** (ทำงานเต็มเวลา) / **Parttime** (ทำงานนอกเวลา) / **พัก** (พักชั่วคราว)

### ระดับ Tier (ความสำเร็จ)

เลือกระดับที่คุณถืออยู่ จะแสดงเป็นแบดจ์บนโปรไฟล์:

| แบดจ์        | ความหมาย                      |
| ------------ | ----------------------------- |
| ⭐ **MDRT**  | Million Dollar Round Table    |
| 🌟 **COT**   | Court of the Table            |
| ✨ **TOT**   | Top of the Table              |

:::note[ยังไม่มีระดับ]
ปล่อยว่างไว้ได้ — ระบบจะไม่แสดงแบดจ์
:::

### ใบรับรองที่คุณถืออยู่

เลือกแท็กใบรับรอง เช่น FA, CPA, CFP, IC — รายการถูกกำหนดโดยแอดมิน ถ้าอยากได้แท็กใหม่ ติดต่อแอดมินของคุณ

### โหมดส่วนตัว (Private Mode)

<Screenshot
	name="team/agent-profile-private"
	alt="สวิตช์เปิดปิดโหมดส่วนตัวในหน้าข้อมูล Agent"
	spec="ให้เห็นสวิตช์โหมดส่วนตัวพร้อมข้อความอธิบายใต้ตัวเลือก"
/>

เปิด/ปิดได้ตลอดเวลา:

- **ปิด (ค่าเริ่มต้น)** — เพื่อนเห็นข้อมูลทั่วไป + ผลงาน (ตัวเลขกิจกรรมรายขั้นตอน แผนที่ความถี่ ยอดขายเทียบเป้าหมาย)
- **เปิด** — เพื่อนเห็นแค่ชื่อและรูป — การ์ดคุณจะขึ้นป้าย "ส่วนตัว" และไม่แสดงตัวเลขใด ๆ

:::note[ผลงานของคุณแสดงที่ไหน]
หน้าตั้งค่านี้ไม่แสดงตัวเลขผลงานของคุณ — สิ่งที่ตั้งที่นี่คือ "ข้อมูลตัวตน" ส่วนผลงานจะแสดงให้เพื่อนดูที่หน้าทีมงานเท่านั้น
:::

:::tip[เคล็ดลับเล็ก ๆ 💡]
- อัปเดต Tier เมื่อบรรลุระดับใหม่ — เป็นแรงบันดาลใจให้เพื่อนด้วย
- ลองเปิดโหมดส่วนตัวสักพัก ถ้ารู้สึกว่ายังไม่อยากเปิดเผยผลงานมากนัก — เปิด/ปิดใหม่ได้เสมอ
:::
