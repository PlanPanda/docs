## โครงสร้างหน่วยงานใน SolidPlan

```text
สำนักงาน (Office)
  └── ทีม (Team)
        └── หน่วย (Unit)

กลุ่ม (Group) ← แยกอิสระจากสำนักงาน
```

| ระดับ          | ตัวอย่าง                                                    |
| -------------- | ---------------------------------------------------------- |
| **สำนักงาน**    | สำนักงานใหญ่ กรุงเทพ, สาขาเชียงใหม่                              |
| **ทีม**        | ทีม A, ทีมประจำเดือน                                          |
| **หน่วย**      | หน่วยที่ 1, หน่วยประกันชีวิต                                   |
| **กลุ่ม**      | กลุ่มวิ่งมาราธอน, กลุ่มอ่านหนังสือ (จัดเอง ไม่ผูกกับสำนักงาน)          |

## วิธีเลือกสังกัดของคุณ

1. ไปที่ **ตั้งค่า → สังกัด** — หน้านี้เขียนไว้ว่า "เลือกหน่วย และกลุ่ม ที่คุณสังกัด"
2. กด **"เพิ่มหน่วย"** เพื่อเลือกสำนักงาน/ทีม/หน่วย (ค้นหาได้ในเมนู) และกด **"เพิ่มกลุ่ม"** เพื่อเลือกกลุ่มอิสระ
3. สังกัดได้หลายที่พร้อมกัน — เช่น อยู่ทั้งสำนักงานกรุงเทพและเชียงใหม่
4. กด **"บันทึก"** — ข้อมูลจะแสดงในหน้าทีมงานทันที

:::note[ถ้ายังไม่มีสังกัดของคุณ]
โครงสร้าง (สำนักงาน/ทีม/หน่วย/กลุ่ม) สร้างโดยแอดมิน — ถ้ายังไม่มีสังกัดของคุณ ติดต่อแอดมินได้เลย
:::

## ผลลัพธ์บนหน้าทีมงาน

เมื่อตั้งสังกัดแล้ว:

- เพื่อนกดปุ่มตัวกรององค์กร → เลือก **สำนักงาน ▾ → ทีม ▾ → หน่วย ▾** หรือ **กลุ่ม ▾** เพื่อดูเฉพาะคนในสังกัดนั้น
- หน้ารายละเอียดของคุณจะแสดง breadcrumb เช่น `สำนักงานใหญ่ › ทีม A › หน่วยที่ 1` พร้อมชิปกลุ่ม

:::note[สังกัดไม่ได้กำหนดการเห็นข้อมูล]
สังกัดเป็นข้อมูลเพื่อกรองและแสดงผลเท่านั้น — **ไม่ได้กำหนดว่าใครเห็นข้อมูลใคร** การเห็นผลงานของกันขึ้นกับความเป็นเพื่อนและโหมดส่วนตัวเสมอ
:::

## สำหรับแอดมิน

- **Admin → จัดการสังกัด** — สร้าง/แก้ไข/ลบ สำนักงาน ทีม หน่วย และกลุ่ม
- การเปลี่ยนแปลงโครงสร้างมีผลทันทีกับทุกคนในระบบ

:::tip[เคล็ดลับเล็ก ๆ 💡]
- เลือกสังกัดให้ตรงกับความจริง — เพื่อนจะได้หาคุณเจอเมื่อกรองตามทีม
- กลุ่มอิสระเหมาะกับกิจกรรมนอกงาน เช่น กลุ่มวิ่ง กลุ่มอ่านหนังสือ
- ย้ายสังกัดเมื่อไหร่ อย่าลืมกลับมาอัปเดตที่นี่
:::

จัดการสังกัดเรียบร้อยแล้ว → กลับไปดู [ภาพรวมทีมงาน](/team/overview/) และเริ่มเติมพลังให้กันและกัน ✨
