## รับคำขอเป็นเพื่อน

1. ที่หัวหน้า **ทีมงาน** กด **ไอคอนกระดิ่ง** (มีตัวเลขแดงเมื่อมีคำขอรอ)
2. เมนูจะแสดง "มีคนชวน N คน" พร้อมรูปและชื่อผู้ส่งคำขอ
3. กด **ติ๊กถูก** เพื่อยอมรับ หรือ **กากบาท** เพื่อปฏิเสธ

| การกระทำ  | ผลลัพธ์                                                                                  |
| --------- | --------------------------------------------------------------------------------------- |
| **ยอมรับ** | เป็นเพื่อนกันทันที — เห็นผลงานกันได้ตามการตั้งค่าความเป็นส่วนตัวของแต่ละฝ่าย                        |
| **ปฏิเสธ** | คำขอหายไป — อีกฝ่ายไม่ได้รับแจ้งว่าคุณปฏิเสธ และสามารถส่งใหม่ได้ภายหลัง                              |

## สิ่งที่เห็นได้ของเพื่อนแต่ละคน

<Screenshot
	name="team/manage-friends-detail"
	alt="แผงรายละเอียดของเพื่อนแสดงสังกัด ผลงานกิจกรรม และกิจกรรมสัปดาห์นี้"
	spec="เลือกเพื่อน 1 คนจากรายชื่อซ้าย ให้แผงขวาแสดงข้อมูลครบทั้งสังกัดและตารางเทียบผลงาน"
/>

คลิกเลือกเพื่อนที่รายชื่อซ้าย แผงขวาจะแสดง:

- ชื่อเรียก ชื่อเต็ม บริษัทที่สังกัด สถานะ (Fulltime/Parttime/พัก) และระดับ (MDRT/COT/TOT)
- **สังกัด** — breadcrumb เช่น `สำนักงาน › ทีม › หน่วย` พร้อมชิปกลุ่ม
- **ผลงานกิจกรรม** — ตารางเทียบสัปดาห์นี้ vs สัปดาห์ก่อน เทียบเดือนนี้ vs เดือนก่อน และแผนที่ความถี่กิจกรรม 20 สัปดาห์และทั้งปี (เลื่อนปีดูย้อนหลังได้)
- **กิจกรรมสัปดาห์นี้** — รายการอ่านอย่างเดียว (ไม่แสดงชื่อลูกค้าของเพื่อน)
- เมื่อสลับมุมมอง "เป้าหมาย" — จะเห็นแถบยอดขายเทียบเป้าหมายรายปีของเพื่อนคนนั้น

:::note[เพื่อนไม่เห็นลูกค้าของกันและกัน]
สิ่งที่แชร์กันคือสรุปจำนวนกิจกรรมและยอดขายรวมเท่านั้น
:::

## เพื่อนแบบส่วนตัว

เพื่อนที่เปิดโหมดส่วนตัวจะมีป้าย **"ส่วนตัว"** — การ์ดไม่แสดงตัวเลข แผงรายละเอียดจะขึ้น 🔒 "เพื่อนส่วนตัว / ไม่แสดงยอดขาย" และ "ไม่มีข้อมูลกิจกรรม" ตามความเหมาะสม

## เลิกเป็นเพื่อน (Unfriend)

<Screenshot
	name="team/manage-friends-unfriend"
	alt="ปุ่มเลิกเป็นเพื่อนในแผงรายละเอียดของเพื่อน"
	spec="เลือกเพื่อนแล้วให้เห็นไอคอนเลิกเป็นเพื่อน (รูปคนลบ) ที่แผงรายละเอียดขวา"
/>

1. เลือกเพื่อนที่รายชื่อซ้าย
2. ที่แผงรายละเอียดขวา กดไอคอน **เลิกเป็นเพื่อน** (รูปคนลบ)
3. กด **"ยืนยัน"** อีกครั้ง → เขาหายออกจากรายชื่อทันที

:::note[เปลี่ยนใจได้เสมอ]
การเลิกเป็นเพื่อนไม่ได้ลบข้อมูลของใคร — แค่เลิกเห็นผลงานกัน จะส่งคำขอใหม่ก็ได้เสมอ
:::

:::tip[เคล็ดลับเล็ก ๆ 💡]
- อย่ากังวลถ้าต้องปฏิเสธคำขอจากคนไม่รู้จัก — อีกฝ่ายไม่รู้ว่าคุณปฏิเสธ
- จำนวนเพื่อนไม่ใช่ตัวชี้วัดความสำเร็จ — คุณภาพของการสนับสนุนกันต่างหากที่สำคัญ
:::
