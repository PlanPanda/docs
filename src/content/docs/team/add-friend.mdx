## วิธีเพิ่มเพื่อน

1. เปิดหน้า **ทีมงาน** → กดปุ่ม **"เพิ่มเพื่อน"** มุมขวาบน
2. เลือกช่องทางจาก 2 แท็บ แล้วกดส่ง

| ช่องทาง     | ใช้เมื่อ                              | เกิดอะไรขึ้น                                                                                                                                                             |
| ----------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **อีเมล**   | รู้อีเมลของเพื่อน                     | ถ้าเพื่อน**มีบัญชีแล้ว** → ส่งคำขอเป็นเพื่อน รอเขากดยอมรับ · ถ้า**ยังไม่มีบัญชี** → ส่งอีเมลเชิญ เมื่อเขาสมัครผ่านลิงก์ในอีเมลจะเป็นเพื่อนกันอัตโนมัติ                                   |
| **ทีมโค้ด** | รู้ทีมโค้ดของเพื่อน เช่น `SP-XXXXXXXX` | ส่งคำขอ → เพื่อนต้องกดยอมรับ (จะเห็นชื่อกันตอนยอมรับ)                                                                                                                                |

ปุ่มในหน้าต่าง: **"ส่งคำเชิญ"** (อีเมล) และ **"ส่งคำขอ"** (ทีมโค้ด)

ข้อความแจ้งที่อาจเจอ:

| ข้อความ                                              | ความหมาย                          |
| ---------------------------------------------------- | -------------------------------- |
| "ส่งคำขอเป็นเพื่อนสำเร็จ" / "ส่งคำเชิญทางอีเมลสำเร็จ"   | ทำรายการสำเร็จ รออีกฝ่ายตอบรับ      |
| "ส่งคำขอไปแล้ว"                                       | คำขอเดิมยังรอเพื่อนตอบอยู่          |
| "ไม่พบ Team Code นี้"                                 | ลองตรวจตัวสะกดของทีมโค้ดอีกครั้ง    |
| "ไม่สามารถเพิ่มตัวเอง"                                 | นี่คือทีมโค้ดของคุณเอง              |

## ทีมโค้ดของคุณเองอยู่ไหน

ดูได้ที่ **ตั้งค่า → โค้ดสร้างทีม** — ทีมโค้ดตัวนี้ใช้ได้ 2 อย่าง:

- เพื่อนใช้ตอนสมัคร/เติมเงินครั้งแรกเพื่อรับโบนัส (ดู [แชร์ให้ทีม](/team/campaign/))
- ใช้พิมพ์ในหน้า "เพิ่มเพื่อน" เพื่อส่งคำขอเป็นเพื่อน

## รับคำขอเป็นเพื่อน

<Screenshot
	name="team/add-friend-request-bell"
	alt="ไอคอนกระดิ่งแจ้งคำขอเป็นเพื่อนพร้อมตัวเลขแดงที่หัวหน้าทีมงาน"
	spec="มีคำขอเป็นเพื่อนค้างอยู่อย่างน้อย 1 รายการ ให้เห็นตัวเลขแดงบนไอคอนกระดิ่ง"
/>

เมื่อมีคนส่งคำขอหาคุณ ที่หัวหน้าทีมงานจะมี **ไอคอนกระดิ่งพร้อมตัวเลขแดง**:

1. กดกระดิ่ง → เมนูแสดงหัวข้อ "มีคนชวน N คน" พร้อมรายชื่อและรูปของผู้ส่งคำขอ
2. กดปุ่มติ๊กถูก = **ยอมรับ** / ปุ่มกากบาท = **ปฏิเสธ** — ยอมรับแล้วเป็นเพื่อนกันทันที

:::note[คำขอที่คุณส่งออกไป]
ระบบไม่มีหน้าให้ย้อนดูคำขอที่ส่งแล้ว — รออีกฝ่ายตอบรับได้เลย ถ้าเขาปฏิเสธหรือยังไม่ตอบ คุณส่งคำขอใหม่ได้ภายหลัง
:::

:::tip[เคล็ดลับเล็ก ๆ 💡]
- แชร์ทีมโค้ดของคุณให้เพื่อนได้เลย — ได้เป็นเพื่อนกันและได้โบนัสพร้อมกัน
- ลิงก์เชิญในอีเมลมีวันหมดอายุ — ถ้าเพื่อนบอกว่าลิงก์ใช้ไม่ได้ ให้ส่งเชิญใหม่
- ถ้าส่งคำขอแล้วขึ้น "ส่งคำขอไปแล้ว" แปลว่าคำขอเดิมยังรอเพื่อนตอบอยู่
:::
