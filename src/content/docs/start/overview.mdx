## ขั้นตอนการเริ่มต้น

### 1. สมัครสมาชิกและตอบคำถามเริ่มต้น

- กด **"สมัครสมาชิก"** กรอกข้อมูล แล้วยืนยันอีเมล (ลิงก์ในอีเมลมีอายุ 24 ชั่วโมง) — ดูรายละเอียดที่ [เข้าสู่ระบบ](/start/login/)
- เข้าสู่ระบบครั้งแรกจะมีคำถาม **"เริ่มต้นใช้งาน"** 4 ข้อ: รู้จักเราจากไหน, อยากให้ช่วยเรื่องไหน, สังกัดบริษัทประกันใด (เลือกเพื่อตั้งสีธีมให้คุ้นเคย), และอยากให้เรียกคุณว่าอะไร — ข้ามไปก่อนได้
- สมัครใหม่จะได้รับ **เครดิตสมัครสมาชิก** เป็นพอยต์เริ่มต้นฟรี (ดูยอดที่ ตั้งค่า → เลือก Package)

### 2. เพิ่มลูกค้าเข้าระบบ

- เริ่มจากชื่อเรียกลูกค้า + เบอร์โทรก่อน แล้วค่อยเติมรายละเอียด — ดูที่ [ระบบลูกค้า](/customers/overview/)
- มีข้อมูลเดิมใน Excel? นำเข้าได้ที่ [ย้ายข้อมูลเข้า-ออก](/import-export/)

### 3. บันทึกกิจกรรมทุกครั้งที่ติดต่อ

- โทรหาลูกค้า → บันทึก · เจอตัว → บันทึก · ส่งข้อเสนอ → บันทึก (ดูต่อที่ [ระบบลูกค้า](/customers/overview/))

### 4. เช็คหน้ารายงานทุกเช้า

- ดูยอดขายเทียบเป้า ผลงานสัปดาห์นี้ และนัดที่กำลังจะถึง (ดู [รายงาน](/daily/report/))

:::tip[เคล็ดลับเล็ก ๆ 💡]
ไม่ต้องใส่ข้อมูลลูกค้าให้ครบทุกฟิลด์ตั้งแต่วันแรก — เริ่มจากชื่อและเบอร์โทรก่อน แล้วค่อยเติมรายละเอียดทีหลังได้เรื่อย ๆ
:::
