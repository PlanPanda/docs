## ส่วนหัวของหน้า

ขึ้นคำว่า "สวัสดี, \{ชื่อคุณ\} · ยินดีต้อนรับสู่ SolidPlan" พร้อมปุ่ม **"รับโค้ดสำหรับชวนเพื่อน"** ไปหน้าสร้างทีมโค้ด (ดู [ทีมงาน](/team/overview/))

## ยอดสะสมตลอดปี 📈

<Screenshot
	name="daily/report-fyp-chart"
	alt="กราฟพื้นที่ยอดสะสมตลอดปีแสดง FYP รายเดือนเทียบเส้นเป้าหมาย"
	spec="เลือกประเภทเป้าไว้ 1 แบบ เช่น MDRT ให้เห็นหัวกราฟ สะสม/เป้า/เปอร์เซ็นต์ เส้นประเหลือง และเส้นแดงตั้ง"
/>

กราฟพื้นที่แสดง FYP สะสมรายเดือนเทียบเป้าหมาย:

- เลือก **ประเภทเป้า** MDRT / COT / TOT ได้ตรงกราฟ (จำไว้ให้อัตโนมัติ)
- หัวกราฟบอก "สะสม X ฿ / เป้า Y ฿ (Z%)" และมุมขวาบอก **"ขาดอีก N ฿"** หรือ **"เกิน N ฿"**
- เส้นประเหลือง = ระดับเป้าหมาย, เส้นแดงตั้ง = จุดเวลาที่ควรทำถึงเป้าตามจังหวะรายเดือน

## ผลงานตามขั้นตอนการขาย 🎯

สองตาราง — **สัปดาห์นี้ เทียบ สัปดาห์ก่อน** และ **เดือนนี้ เทียบ เดือนก่อน** แยกตาม 5 ขั้นตอน (ติดต่อ / สัมพันธ์ / บริการ / เสนอขาย / ปิดการขาย) พร้อมลูกศร ▲ เขียวขึ้น · ▼ แดงลง · ▬ เทาคงที่

**ทำไมต้องดู:** ถ้า "ติดต่อ" เยอะมากแต่ "เสนอขาย/ปิดการขาย" แทบไม่ขยับ — อาจถึงเวลาปรับกลยุทธ์การตามงานแล้ว

## กิจกรรมรอบ 20 สัปดาห์ 🗓️

แผนที่ความถี่กิจกรรม 20 สัปดาห์ล่าสุด × 5 ขั้นตอน (แต่ละขั้นตอนคนละสี) — สีเข้ม = ทำเยอะ ชี้ที่ช่องไหนจะบอกว่า "\{ขั้นตอน\} · N กิจกรรม · วันที่" และ **กดที่ตารางเพื่อสลับแสดง/ซ่อนตัวเลข** ในช่องได้เลย

## กิจกรรมในหนึ่งปี 🗓️

กราฟช่องสี่เหลี่ยมรายวันแบบ GitHub contribution ทั้งปี (ปีแสดงเป็น พ.ศ.) — สีเข้ม = กิจกรรมเยอะ, กดลูกศร "ปีก่อนหน้า / ปีถัดไป" เพื่อย้อนดูปีที่ผ่านมา

**ทำไมต้องดู:** เห็นทันทีว่าเดือนไหนทำงานหนัก เดือนไหนห่างหายจากลูกค้านานเกินไป จะได้กระจายงานให้สมดุล

กราฟกรวยแนวนอนแสดงจำนวนกิจกรรม 30 วันล่าสุดตามลำดับขั้น: ติดต่อ → สัมพันธ์ → เสนอขาย → ปิดการขาย → บริการ พร้อมเปอร์เซ็นต์เทียบขั้นบนสุด เห็นทันทีว่ากิจกรรม "รั่ว" ไปหยุดที่ขั้นไหน

## กิจกรรมที่จะถึง ⏰

รายการนัดหมายล่วงหน้าของคุณ:

- กดชื่อลูกค้าเพื่อไปที่หน้าลูกค้าคนนั้นทันที
- แก้ไข / ลบ / สลับขั้นตอนได้ตรงการ์ดเลย
- ถ้าไม่มีนัดจะขึ้น "ยังไม่มีนัดหมายล่วงหน้า" — ลองวางแผนนัดใหม่ที่ [ปฏิทิน](/daily/calendar/)

:::tip[เคล็ดลับเล็ก ๆ 💡]
เปิดหน้ารายงานทุกเช้าเป็นนิสัย — ใช้เวลาแค่ 1-2 นาที แต่รู้ทั้งยอดขายเทียบเป้า จังหวะการทำงาน และนัดที่ต้องเตรียมวันนี้
:::
